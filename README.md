# Five Oaks Studio

Safe first build of Lori's separate Five Oaks production app.

## What works now

- Voice preview using voices already installed on the phone or laptop
- Script and project saving in the browser
- Uploading one still image
- 9:16 and 16:9 camera-motion previews
- Watermark-free video export when the browser supports canvas recording
- Offline caching after the site has been opened once

## Safety

This build does not change phone settings, read contacts, scan photos, or upload files. It can only use an image the user deliberately selects. Saved projects stay in that browser's local storage.
