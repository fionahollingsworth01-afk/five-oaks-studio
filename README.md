# Five Oaks Studio

Separate production app for Lori. Diamond and the Five Oaks story app remain untouched.

## Version 0.2

- iPhone-friendly home screen
- voice preview using device voices
- saved scripts and project settings in local browser storage
- 9:16 and 16:9 moving-image clips
- zoom, pan, rise, fall, and fade controls
- browser video export where supported
- project backup and import
- installable web-app manifest and offline cache

## Important limits

Browser voice preview cannot reliably save the built-in voice as MP3 or WAV. Downloadable Microsoft voiceovers need Azure Speech connected through a secure server. Full AI acting also needs a cloud video engine; this build creates watermark-free camera movement from a still image.
